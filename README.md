# HeThongTuDongQuanTriVaQuanLyHieuSuatMang
Xây dựng một hệ thống quản trị mạng sử dụng Python + Netmiko có các chức năng quản lý thiết bị, giám sát hiệu suất, thu thập dữ liệu, cảnh báo sự cố, sao lưu cấu hình và tạo báo cáo. Hệ thống phải hoạt động với nhiều thiết bị và có khả năng xử lý khi một thiết bị mất kết nối.
